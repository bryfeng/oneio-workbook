02

Where we can build on this

These are the services we would build around, with the proposed endpoints in the API brief.

Proposed

Business wallets

Account / wallet services + DynamicGive the business a shared wallet record that connects its team and signing permissions, with Gateway using it alongside other products.

Flow collection

Gateway + orchestration + Flow adapterUse Flow for the collection, then check that the funds reached the wallet the merchant selected.

Crypto batches

Payments / disbursements + custody or wallet signerBuild on the dashboard’s batch handling if we can, adding crypto checks and tracking each recipient before retrying any payment.

Auto-conversion

Custody + trading + ledger + reconciliationLet the merchant agree the conversion instructions up front, then connect deposit checks, any sweep, the trade and fiat credit.
